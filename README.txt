KAMUI DOWNLOADER WEBSITE

Website files:
- index.html: main website page
- styles.css: layout, colors, and typography
- app.js: website behavior, download links, version, and package details
- assets/: logo, favicon, social preview, and screenshots

The download buttons, displayed version, and package sizes are configured near the top of app.js.

Current release: v1.1.7
GitHub repository: https://github.com/hanzalawaqar/Kamui-Downloader

To preview the website, open index.html in a modern web browser.
To publish it, upload the complete kamui-website folder to your web host.
